Scoring model

Adjusted contribution = Sweet Scent horde probability × horde size × current event points × temporal exclusivity.

Temporal exclusivity is 12 ÷ the number of season/time combinations in which the encountered species is available.

With live filtering enabled, the dashboard automatically uses the current event season and PokeMMO time window. Disable it to use the manual Season and Time selectors.

For player views, a route context is excluded when that player has already caught any scoring evolution family available in the context. This rule is configurable in config/dashboard_config.json.

All calculations use location_id as the authoritative map key. The route or location name is shown for readability; repeated names include their Location ID.
